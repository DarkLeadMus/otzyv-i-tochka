# Отзыв и Точка

Система опросов для сбора замечаний гостей по направлениям обслуживания.
Учебный проект, ЛР 2, вариант 29.

## Что в репозитории
- docs/backlog.md — backlog продукта
- docs/scenario-guest.md — сценарий «Гость проходит опрос»
- docs/algorithm-validate.md — алгоритм проверки допустимости ответа

## Процесс
Гибрид Scrum и Kanban, спринт 1 неделя.
Работа ведётся в ветках feature/*, в main — через merge после review.

## Формат сообщений коммитов
тип: краткое описание (docs, feat, fix, test)
Пример: docs: add acceptance criteria for US-02
